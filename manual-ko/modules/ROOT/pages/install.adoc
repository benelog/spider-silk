= 설치
:navtitle: 설치

Spider Silk는 Java 21 이상이 필요하다.
릴리스는 https://central.sonatype.com/namespace/net.benelog[Maven Central]에 게시되므로, 빌드에는 기본 저장소 외의 저장소가 필요 없다.
현재 버전은 `{project-version}`이다.
https://github.com/{project-repo}/blob/main/CHANGELOG.md[CHANGELOG.md]가 각 릴리스에서 바뀐 것을 나열한다.

== Gradle

[source,groovy,subs="attributes+"]
----
repositories {
    mavenCentral()
}

dependencies {
    implementation '{project-group}:spider-silk-core:{project-version}'
    testImplementation '{project-group}:spider-silk-test:{project-version}'
}
----

== Maven

Maven은 기본적으로 Central에서 해석하므로, `pom.xml`은 의존성만 선언하고 그 밖에는 아무것도 선언하지 않는다:

[source,xml,subs="attributes+"]
----
<dependencies>
  <dependency>
    <groupId>{project-group}</groupId>
    <artifactId>spider-silk-core</artifactId>
    <version>{project-version}</version>
  </dependency>
  <dependency>
    <groupId>{project-group}</groupId>
    <artifactId>spider-silk-test</artifactId>
    <version>{project-version}</version>
    <scope>test</scope>
  </dependency>
</dependencies>
----

== Hello, world

[source,java]
----
import net.benelog.spidersilk.App;
import net.benelog.spidersilk.WebResponse;

public class Main {

    public static void main(String[] args) {
        App app = new App();
        app.get("/hello/{name}", req -> WebResponse.text("Hello, " + req.pathParam("name")));
        app.start(8080);
    }
}
----

[source,bash]
----
$ curl localhost:8080/hello/silk
Hello, silk
----

`spider-silk-core`는 내장 Jetty를 함께 가져오므로, 요청을 서비스하는 데 그 밖에는 아무것도 필요 없다.
같은 앱을 내장 Tomcat이나 Undertow에서 실행하려면 `spider-silk-tomcat`이나 `spider-silk-undertow`를 추가한다; xref:server.adoc#choosing[서버 고르기]을 참고한다.
대신 외부 서블릿 컨테이너에 배포하려면 xref:deployment.adoc[배포]를 참고한다.
템플릿은 별도 설정 없이 jte로 렌더링된다.
xref:freemarker.adoc[FreeMarker], xref:handlebars.adoc[Handlebars], xref:thymeleaf.adoc[Thymeleaf]는 별도의 모듈이며, 같은 방식으로 추가한다.
xref:websocket.adoc[`spider-silk-jetty-websocket`]은 WebSocket 엔드포인트를 추가하며, Jetty에서만 동작한다.
xref:openapi.adoc[`spider-silk-openapi`]는 라우트 목록을 OpenAPI 문서로 바꾼다.

== 좌표, 패키지, 모듈 이름

`{project-group}`은 하나의 문자열이며, 의도적으로 세 가지 방식으로 쓰인다.

[cols="1,3",options="header"]
|===
| 어디에 | 무엇인가

| 그룹 id
| `{project-group}`, 아티팩트 id는 모듈 자체의 이름 — `{project-group}:spider-silk-core`

| 패키지 루트
| `{project-group}`, 코어가 이를 소유하고 다른 모듈은 각각 하위 패키지 — `{project-group}.tomcat`, `{project-group}.jetty.websocket`

| `Automatic-Module-Name`
| jar가 담는 패키지 루트로, `import`와 모듈 경로가 같은 이름을 쓴다 — `{project-group}`, `{project-group}.tomcat`, `{project-group}.jetty.websocket`
|===

xref:gradle-plugin.adoc[Gradle 플러그인]은 같은 id인 `{project-group}`으로 적용되고, xref:maven-parent.adoc[Maven 부모 POM]은 `{project-group}:spider-silk-maven-parent`다.
https://github.com/benelog/spider-silk/blob/main/notes/decisions.md[결정 32]가 그 근거를 제시한다.
