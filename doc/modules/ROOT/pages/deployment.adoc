== An external servlet container

Deploy to an external servlet container by skipping `start` and mapping `AppServlet` yourself:

[source,java]
----
ServletContextHandler context = new ServletContextHandler(ServletContextHandler.SESSIONS);
context.addServlet(new ServletHolder(new AppServlet(app)), "/*");
----

`AppServlet` is a standard servlet, so it runs on any container (Tomcat and others), not just Jetty.
An embedded Tomcat that `app.start(port)` runs itself is a different thing, and lives in `spider-silk-tomcat`: see xref:tomcat.adoc[Tomcat], and xref:undertow.adoc[Undertow] for the third option.
Deploying to a container you did not start, exclude the bundled Jetty:

[source,groovy,subs="attributes+"]
----
implementation('{project-group}:spider-silk-core') {
    exclude group: 'org.eclipse.jetty.ee10'
}
----

== Precompiled templates

jte compiles templates at runtime by default, which requires a JDK on the deployment machine.
For production, precompile with the https://jte.gg/pre-compiling/[jte Gradle plugin] and pass the engine through the `JteTemplates(TemplateEngine)` constructor.
The suffix applies either way, so no handler changes.
